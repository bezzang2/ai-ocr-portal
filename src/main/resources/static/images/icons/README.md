# 아이콘 자산

Figma 레이아웃(232:744)에서 확인된 아이콘은 `ic/16/user`, `ic/16/notifications`,
`iconamoon:arrow-right-2`, `mage:refresh`, `ic/24/chevron-*` 등 Iconify 계열
네이밍입니다. 화면마다 개별 PNG/SVG를 잘라 쓰는 방식은 유지보수 비용이 커지므로,
다음 중 하나로 표준화하는 것을 권장합니다.

1. **아이콘 폰트(Font Awesome 등) + class 기반 사용** — 스크린리더/폰트 로딩 실패 시
   대체 텍스트가 깨끗하게 처리됨. 리게처 텍스트 방식(`<span>icon_name</span>`)은 피할 것.
2. **자체 SVG 스프라이트** — 브랜드 고유 아이콘(로고 등)이 많을 경우.

이 폴더는 로고 등 아이콘화하기 애매한 개별 이미지 자산 전용으로 쓰고,
범용 UI 아이콘(화살표/유저/알림 등)은 위 1번 또는 2번 방식으로 별도 관리하세요.
